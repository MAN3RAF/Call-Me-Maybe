# Call-Me-Maybe

## Description

Call-Me-Maybe is a project that implements robust function calling for Large Language Models (LLMs) using constrained decoding. The primary goal is to reliably convert natural language user prompts into precisely structured JSON objects corresponding to specific function definitions and their parameters. By overriding the next-token probability distribution, the system ensures that the LLM only outputs structurally valid JSON matching a predefined schema.

## Instructions

```bash
    --functions_definition data/input/functions_definition.json \
    --output data/output/function_calls.json

# Or using the provided Makefile
make run
```

## Algorithm explanation

The project employs constrained decoding at the token level (logit masking). During each generation step, the model computes the logits (un-normalized probabilities) for the entire vocabulary. Our algorithm intercepts this process and masks out (sets to negative infinity) any token that would result in an invalid sequence according to our state machine.

1. **JSON Structure Enforcement:** We synthetically inject structural tokens like `{"prompt": "...", "name": "` without querying the model.
2. **Function Selection:** The model is constrained to only output tokens that form one of the allowed function names.
3. **Parameter Generation:** Based on the parameter type (number, boolean, string), the token generation is restricted to a specific character set (e.g., only digits and commas for numbers).

## Design decisions

- **Token-level constraint over prompt-engineering:** Instead of hoping the model follows formatting instructions, we physically prevent it from outputting invalid characters.
- **Prefix Path Matching:** To generate valid function names, we pre-encode the allowed names and check the generated tokens against these valid prefixes at each step.
- **Data Type Handlers:** Distinct state loops for `number`, `string`, and `boolean` types to ensure valid data values in the resulting JSON output.

## Performance analysis

- **Accuracy:** The structural accuracy of the generated JSON is virtually 100%, as the model is mathematically prohibited from generating malformed fields or hallucinating unsupported function names.
- **Speed:** The generation is slightly slower than unrestricted decoding due to the overhead of recalculating allowed tokens at every step and prefix matching, but remains well within acceptable limits for a Small LLM.
- **Reliability:** Exceptional reliability when parsing varied data types, gracefully handling token boundary differences for strings and floats.

## Challenges faced

- **Tokenization differences:** LLMs tokenize numbers and strings unpredictably. A single digit or a combination of digits could be one token or multiple. Handling boundary tokens (like commas separating arguments) required precise checking.
- **Sub-word fragments:** Ensuring that function strings matched perfectly token-by-token required a dynamic prefix matching approach (`allowed_paths`) rather than simple string comparisons.
- **Escaping Special Characters:** Making sure the final decoded string was safely parsed by Python's `json.loads` involved carefully handling specific whitespace or quotation characters generated by the model.

## Testing strategy

Validation is performed by feeding the system a suite of prompts (`function_calling_tests.json`) alongside diverse schema definitions (`functions_definition.json`). The final generated outputs (`function_calls.json`) are evaluated to confirm that:

1. They parse successfully as JSON.
2. They map to the correct function name.
3. Their parameters conform to the exact types (integer, boolean, string, float) requested by the schema.

## Example usage

If provided the following function definition (e.g., `fn_add_numbers(a: number, b: number)`) and the prompt: "what is the sum of 5 and 10", the execution ensures the LLM's raw generation strictly outputs:

```json
{
  "prompt": "What is the sum of 5 and 10",
  "name": "fn_add_numbers",
  "parameters": {
    "a": 5.0,
    "b": 10.0
  }
}
```

Run it via:

```bash
python -m src
```
